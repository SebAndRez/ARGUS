# docs/files/ — Internal foundational documents

This folder holds ARGUS's foundational doctrine documents:

- Filosofía ARGUS
- Doctrina Operacional ARGUS
- Modelo de Dominio ARGUS
- Diccionario Oficial ARGUS

These are internal governance documents and are **not versioned** in this repository. `.gitignore` excludes everything in this folder except this file. Store the actual `.docx` files here locally; do not add them with `git add -f`.

If you need a copy, ask a project maintainer through an internal channel — not through a public issue or pull request.

See [`docs/SECURITY_AND_DOCUMENT_HANDLING.md`](../SECURITY_AND_DOCUMENT_HANDLING.md) for the full policy on internal vs. public documentation.

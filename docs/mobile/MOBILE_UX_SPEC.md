# ARGUS Mobile UX Spec

## Pantallas

- Onboarding.
- Permisos.
- Explicacion de sensores.
- Activar Safety Agent.
- Contactos de emergencia.
- Ubicacion de emergencia.
- Timeout/check-in.
- Check-in modal.
- Estoy bien.
- Necesito ayuda.
- Herido.
- Atrapado.
- No puedo moverme.
- Falsa alarma.
- Historial.
- Privacidad.
- Borrar datos.
- Modo demo/test.

## Reglas UX

- Lenguaje claro.
- Botones grandes.
- No panico.
- Cuenta regresiva visible.
- Cancelar falsa alarma.
- SOS siempre visible.
- Privacidad nunca escondida.
- No prometer contacto oficial si no existe.

## Microcopy

- "Posible accidente detectado. Confirme si esta bien."
- "Esto no contacta automaticamente servicios de emergencia."
- "Puede cancelar si fue falsa alarma."
- "Su ubicacion se comparte solo segun sus permisos."

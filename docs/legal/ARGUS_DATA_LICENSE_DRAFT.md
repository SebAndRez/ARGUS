# ARGUS Data License Draft

Este documento es un borrador y no constituye asesoria legal definitiva.

## Uso Limitado

ARGUS Data es de uso limitado. El acceso publico no otorga derecho a explotar,
revender, copiar, automatizar, integrar o crear datasets derivados.

## Prohibiciones

- No reventa.
- No scraping.
- No extraccion masiva.
- No datasets derivados.
- No entrenamiento de modelos sin permiso.
- No integracion institucional sin contrato.
- No uso gubernamental sin autorizacion formal.
- No redistribucion de reportes ciudadanos.

## API

La API requiere autorizacion, API key, rate limits, trazabilidad, auditoria y
contrato. El abuso puede causar suspension.

## Datos Sensibles

Datos medicos, contactos de emergencia, ubicacion precisa, identidad, missing
persons y sensores quedan excluidos del uso publico.

## Derechos ARGUS

ARGUS conserva derechos sobre estructura, normalizacion, correlacion, analisis,
interfaces, datos derivados y capas propietarias, salvo derechos de fuentes
externas o usuarios segun corresponda.
